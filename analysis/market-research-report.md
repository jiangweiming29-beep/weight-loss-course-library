## 二、需求侧分析：减肥刚需 + 外卖依赖

### 2.1 中国超重肥胖现状（需求基数）

| 指标 | 数据 | 来源 |
|------|------|------|
| 成人超重肥胖率 | **50.7%** (2025年首次突破50%) | 国家卫健委 |
| 预测 2030 年肥胖率 | **70.5%** | 国家卫健委监测报告 |
| 有减重意愿的公众 | **73%** | 全民体重管理调查 |
| 愿意付诸行动 | **64%** | 同上 |
| 能融入日常生活 | **仅38%** | 同上 |
| 儿童青少年超重肥胖率 | 每人中就有1人 | 国家卫健委 |
| 超重肥胖相关医疗费用 | 占医保总额**12%+**，2030年预计**4180亿元** | 国家卫健委 |

**解读**：中国有超过 **7亿** 成年人超重或肥胖（14亿 × 50.7%）。其中 73% 想减重，也就是约 **5.1亿人** 有明确的减重需求。但只有 38% 能做到——**执行力是最大痛点。**

### 2.2 中国外卖市场现状（使用场景基数）

| 指标 | 数据 | 来源 |
|------|------|------|
| 2025年在线外卖市场规模 | **突破2万亿元** | 网经社 |
| 外卖用户规模 | **5.53亿人** | MCR嘉世咨询 |
| 日均订单量 | **2.5亿单**（补贴战后） | 网经社 |
| 用户主力人群 | **18-30岁年轻人** | 豆丁网行业报告 |
| 品质化需求趋势 | 追求**健康、营养、美味**的食品 | 2025外卖消费者画像报告 |
| 减脂期尝试外卖轻食的上班族 | **68%** | 2026科学点外卖指南 |
| 坚持不到两周放弃 | **52%** | 同上 |

**解读**：5.53亿外卖用户中，18-35岁年轻群体是主力。这个群体恰恰是减肥需求最强烈的（久坐+外卖=肥胖高发），也是数字化产品最容易触达的。**68%的人试过减脂外卖但52%两周放弃——说明现有的"健康外卖"方案不够好。**

### 2.3 用户痛点验证

来自调研数据的直接证据：

| 痛点 | 数据占比 | 与你产品的对应关系 |
|------|---------|-------------------|
| "见效慢，难以坚持" | 57% | 事前决策让每次点餐都有正反馈 |
| "工作忙没时间" | 33% | 截图/拍照即用，零时间成本 |
| "过程枯燥中途放弃" | 23% | AI推荐有新鲜感，每次不同 |
| 误判自身体型 | 33% | 个性化体脂数据纠正认知 |
| 减肥后反弹 | 大量用户 | 闭环调整防反弹 |

## 五、TAM/SAM/SOM 测算

```
中国外卖用户：5.53亿人
× 超重肥胖率：50.7%
× 有减重意愿：73%
= 约 2.05亿人  ← 这是中国市场的TAM
```

### 5.2 SAM（可服务市场）

```
TAM：2.05亿人
× 18-35岁占比：~55%
× 智能手机+微信活跃用户：~90%
= 约 1.01亿人  ← 你的核心可服务市场
```

### 5.3 SOM（可获取市场 - 3年目标）

```
SAM：1.01亿人
× 假设3年渗透率：2%（参考薄荷健康6000万/14亿=4.3%，取保守值）
= 约 200万用户

付费转化率：10%（低于行业39.9%均值，取保守值）
× 年费：¥228/年（¥19/月，低于行业$12.99/月≈¥93/月）
= 年收入潜力：约 4560万元/年
```

### 5.4 全球市场扩展潜力

```
全球外卖市场：$4253亿
```

## 七、SWOT 分析

### Strengths（优势）

- **场景创新**：外卖+减脂+AI推荐是无人做的蓝海交叉
- **事前决策**：从根本上解决"记录了但没用"的行业痛点
- **高频使用**：外卖是每日刚需，天然解决App留存率问题
- **AI成本下降**：Gemini Flash等模型成本已降到可承受

### Weaknesses（劣势）

- 中餐热量估算误差大（±20%）
- 外卖菜品数据库需要人工建设
- 单人开发资源有限
- 没有品牌积累和用户基础

### Opportunities（机会）

- 中国50.7%成人超重，5亿+减重需求人群
- AI个性化营养6倍增长风口
- 国家"体重管理年"政策红利
- 蚂蚁投资薄荷健康，大厂仍在关注赛道
- Calorie AI验证了AI拍照赛道（$10M A轮）

### Threats（威胁）

- 美团/饿了么自建健康推荐功能
- 薄荷健康/Keep增加AI推荐能力
- MyFitnessPal进入中国市场
- AI大厂（字节/百度）做免费竞品
- 减肥App行业43%流失率

## 八、市场进入策略建议

### Phase 1 — 种子验证（0-3个月）

**目标**：验证"外卖+减脂+AI推荐"需求是否存在

- 做微信小程序MVP（不用下载，降低使用门槛）
- 聚焦 Top 50 常见外卖品类
- 在小红书/抖音发"减脂外卖点餐攻略"内容引流
- 目标：1000个种子用户，验证留存率 > 20%（行业3.9%的5倍）

### Phase 2 — 增长验证（3-6个月）

**目标**：验证付费意愿

- 上线AI拍照识别 + 个性化推荐完整功能
- 开通¥19/月Pro订阅
- 与3-5家健康外卖商家合作（佣金模式）
- 目标：1万用户，5%付费转化

### Phase 3 — 规模化（6-12个月）

**目标**：证明商业模式可规模化

- 外卖菜品库扩展到200+品类
- 上线闭环反馈和周报功能
- 投放小红书/抖音信息流广告
- 目标：10万用户，10%付费转化

### Phase 4 — 融资/扩张（12-24个月）

- 如果Year 1数据跑通，可寻求天使轮/Pre-A融资
- 参考 Calorie AI 路径（50万日活→$10M A轮）
- 扩展到东南亚市场（GrabFood/Foodpaday适配）

## 九、核心结论

### 9.1 市场是否存在？

**是的，而且非常大。**

| 维度 | 结论 |
|------|------|
| 需求规模 | 中国2亿+有减重意愿的外卖用户 |
| 市场增速 | AI营养6倍增长，减肥市场7-9% CAGR |
| 付费意愿 | 减肥App付费转化率39.9%，全品类最高 |
| 竞争空白 | 无人同时做"个性化+外卖+事前决策" |
| 政策环境 | 国家"体重管理年"行动，政策利好 |
| 资本认可 | Calorie AI $10M A轮，薄荷健康获蚂蚁投资 |

### 9.2 最大的风险是什么？

**不是市场不够大，而是留存率。**

减肥App行业43%流失率、15天后仅3.9%留存。但你的产品有两个天然优势对抗这个问题：

1. **外卖是每日刚需**——用户每天都要点外卖，不需要额外"打开App记录"的动力
2. **事前决策有即时价值**——用户点之前就得到帮助，而不是吃完才后悔

如果能做到"用户每次点外卖都先看一眼你的推荐"，留存率有望达到30%+，远超行业均值。

### 9.3 最终建议

```
方向：值得做。市场大、需求强、无人做、政策好。

第一步不要想太多，先做MVP验证：
- 微信小程序（不用下载）
- Top 50 外卖菜品热量库
- TDEE计算器 + 今日预算
- 文字输入菜名 → AI推荐搭配
- 1000个种子用户看留存率

如果15天留存率 > 20%，这个方向就值得继续投入。
```
