# 减肥减脂课程库

> 汇集全网热门科学减脂课程、训练方案、饮食指南的知识库

## 简介

本课程库系统性地整理了全网有热度的减肥减脂相关资料和课程，涵盖：

- **科学减脂理论** - 基础代谢率、TDEE、热量缺口等核心概念
- **饮食营养方案** - 高蛋白饮食、地中海饮食、轻断食、生酮饮食等
- **线上健身课程** - 帕梅拉、刘畊宏、周六野等热门博主课程
- **线下减肥训练营** - 国内5家代表性减肥训练营机构
- **力量训练计划** - 减脂增肌的科学训练方案
- **国际减脂项目** - Udemy、Noom、WeightWatchers等国际平台课程
