# 饮食营养方案

> 科学的饮食是减脂的核心。以下是全网热门的减脂饮食方案对比

## 方案对比总表

| 方案 | 难度 | 蛋白质 | 脂肪 | 碳水 | 可持续性 | 适合人群 |
|------|------|--------|------|------|----------|---------|
| 高蛋白饮食 | 入门 | 30-40% | 30-40% | 30-40% | 高 | 所有人 |
| 80/20饮食 | 入门 | 30-40% | 30-40% | 30-40% | 极高 | 有基础者 |
| 间歇性断食 | 中级 | 灵活 | 灵活 | 灵活 | 高 | 想简化饮食者 |
| 生酮饮食 | 高级 | 适量 | 极高 | 极低 | 中 | 有经验者 |
| 地中海饮食 | 入门 | 15-20% | 30-40% | 40-55% | 极高 | 追求全面健康者 |

## 1. 高蛋白饮食法 (High Protein Diet)

**来源**: SET FOR SET

### 核心原理

- **食物热效应(TEF)**: 蛋白质消化消耗更多热量
- **饱腹感**: 蛋白质饱腹感最强，减少饥饿
- **血糖稳定**: 减少糖 cravings
- **保护肌肉**: 减脂期间维持肌肉量和基础代谢

### 宏量营养素比例

```
蛋白质: 30-40%
脂肪:   30-40% (不低于30%)
碳水:   30-40%
```

### 推荐食物

- 瘦肉（鸡胸肉、瘦牛肉）
- 鱼虾海鲜
- 鸡蛋
- 乳制品（希腊酸奶、 cottage cheese）
- 蛋白粉（每日1-2份，不超过）

### 注意事项

- 多样化蛋白质来源
- 平衡三大营养素，不要忽略碳水和脂肪
- 注意份量控制（蛋白质仍有热量）
- 蛋白粉缺乏全食物的TEF效益

---

## 2. 80/20 饮食法

**来源**: SET FOR SET

### 核心理念

> 80%的食物来自天然全食物，20%可以吃加工食品或零食。不禁止任何食物。

### 食物分类

| 类别 | 占比 | 食物举例 |
|------|------|---------|
| 全食物 | 80% | 水果、蔬菜、瘦肉、全谷物、坚果、健康脂肪 |
| 灵活食物 | 20% | 零食、甜食、快餐、精制碳水 |

### 优势

- 无食物禁忌，心理压力小
- 全食物体积大热量低，自然限制热量
- 研究证明灵活饮食长期坚持效果最好
- 适合有基础营养知识的人群

### 实操建议

- 每周备餐1-2天
- 刚开始时每餐固定2个熟悉选项轮换
- 先学会辨别"全食物"vs"加工食品"

## 3. 间歇性断食 / 轻断食 (Intermittent Fasting)

**来源**: SET FOR SET / 百度健康

### 断食模式

| 模式 | 方法 | 适合人群 |
|------|------|---------|
| 16:8法 | 16小时断食，8小时进食 | 上班族、入门 |
| 20:4法 | 20小时断食，4小时进食 | 进阶者 |
| OMAD | 每日一餐 | 高级 |
| 5:2法 | 5天正常，2天极低热量 | 灵活人群 |
| 隔日断食 | 隔天断食 | 严格控重者 |

### 科学原理

- 限制进食窗口 → 自然减少热量摄入
- 改善胰岛素敏感性
- 触发细胞自噬(autophagy)
- 改善LDL胆固醇和甘油三酯
- 提升心脏代谢健康

### 不适合人群

- 有进食障碍史
- 孕妇/哺乳期女性
- 某些疾病患者（需医生指导）

### 实操建议

- 断食期间保持水分摄入
- 进食窗口内选择营养密集食物
- 从较短断食时间开始，逐步增加

---

## 4. 生酮饮食 (Keto Diet)

**来源**: 百度健康医学科普

### 核心原理

通过极低碳水摄入 → 身体切换为脂肪供能（酮症状态）

```
正常状态: 碳水 → 葡萄糖 → 供能
生酮状态: 脂肪 → 酮体 → 供能
```

### 宏量营养素比例

```
脂肪:   70-75%
蛋白质: 20-25%
碳水:   5-10% (通常<50g/日)
```

### 可与间歇性断食结合

- 结合可加速进入生酮状态
- 轻断食+生酮 = 代谢开关双重触发

### 注意事项

- 需监测酮体水平
- 可能有"酮流感"过渡期
- 糖尿病患者需医生指导
- 长期可持续性存争议
- 不适合自行尝试的新手

## 5. 地中海饮食 (Mediterranean Diet)

**来源**: SET FOR SET

### 认可度

- WHO（世界卫生组织）推荐
- AHA（美国心脏协会）认可
- 多年蝉联"最佳综合饮食"

### 核心特点

| 大量摄入 | 适量摄入 | 少量/避免 |
|---------|---------|---------|
| 橄榄油 | 乳制品 | 非鱼肉类 |
| 豆类 | 红酒 | 加工食品 |
| 全谷物 | | 添加糖 |
| 水果蔬菜 | | |
| 鱼类 | | |
| 坚果 | | |

### 宏量营养素比例

```
蛋白质: 15-20% (建议增至25-30%)
脂肪:   30-40%
碳水:   40-55%
```

### 健康效益

- 降低心血管疾病风险
- 改善血糖控制
- 降低某些癌症风险
- 降低认知疾病风险
- 改善糖尿病指标

### 注意

- 可能不会快速减重（偏向长期健康）
- 需要持续备餐和规划
