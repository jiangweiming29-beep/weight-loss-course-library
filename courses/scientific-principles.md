# 科学减脂理论

> 减脂入门必学：理解身体代谢机制，才能科学高效地减脂

## 1. 热量平衡与基础代谢率 (BMR/TDEE)

**来源**: 民福康 / 北京大学人民医院临床营养科

### 核心公式

```
男性 BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄(岁) + 5
女性 BMR = 10×体重(kg) + 6.25×身高(cm) - 5×年龄(岁) - 161

TDEE = BMR × 活动系数
```

### 活动系数对照表

| 活动水平 | 系数 | 说明 |
|---------|------|------|
| 久坐不动 | 1.2 | 办公室工作，无运动 |
| 轻度活动 | 1.375 | 每周1-3次运动 |
| 中度活动 | 1.55 | 每周3-5次运动 |
| 重度活动 | 1.725 | 每日高强度运动 |

### 减脂热量计算

- 每日摄入热量 = TDEE - 300~500大卡
- 安全底线: 女性≥1200大卡/日，男性≥1500大卡/日
- 健康减重速度: 每周0.5-1kg
- 3500大卡缺口 ≈ 1斤脂肪

### 示例计算

> 70kg男性，30岁，175cm，久坐
> BMR = 10×70 + 6.25×175 - 5×30 + 5 = 1649大卡
> TDEE = 1649 × 1.2 = 1979大卡
> 减脂期摄入 = 1979 - 500 = 1479~1679大卡

## 2. 运动与饮食的科学搭配

**来源**: 民福康 / 首都医科大学附属北京友谊医院

### 运动建议

| 类型 | 频率 | 时长 | 备注 |
|------|------|------|------|
| 有氧运动 | 每周≥3次 | ≥150分钟/周 | 快走/慢跑/游泳 |
| 力量训练 | 每周2-3次 | 20-30分钟/次 | 俯卧撑/深蹲/哑铃 |

### 运动心率区间

- 最佳燃脂心率: 最大心率的60%-70%
- 最大心率 ≈ 220 - 年龄
- 中等强度: "能说话但有点喘"

### 消耗参考

| 消耗范围 | 性别 | 说明 |
|---------|------|------|
| 1500-2200大卡/日 | 女性 | 含运动 |
| 1800-2500大卡/日 | 男性 | 含运动 |

### 注意事项

- 不可低于 BMR×1.1，避免基础代谢下降
- 额外运动消耗 300-500大卡/日（如快走45分钟≈300大卡）
- 避免极端运动致关节损伤
- 单纯靠"狂运动"易反弹，必须结合饮食控制

## 3. 睡眠与激素对减脂的影响

**来源**: 民福康 / 广州市妇女儿童医疗中心临床营养科

### 睡眠对激素的影响

```
睡眠不足 → 饥饿素(Ghrelin)↑ + 瘦素(Leptin)↓ → 食欲亢进 → 过量进食
```

### 建议

| 项目 | 建议值 |
|------|--------|
| 睡眠时长 | 7-9小时/晚（成年人） |
| 蛋白质摄入 | 1.2-1.6g/kg体重 |
| 膳食纤维 | 25-30g/日 |
| 每日饮水 | 1500-2000ml |
| 添加糖 | <25g/日 |

### 特殊人群注意

- **孕妇/哺乳期**: 额外补充300-500大卡，摄入≥2000大卡
- **老年人**: ≥1500大卡，蛋白质1.2-1.5g/kg，预防肌肉流失
- **糖尿病患者**: 需结合药物调整，避免低血糖
- **儿童青少年**: 保证营养，缺口≤300大卡
