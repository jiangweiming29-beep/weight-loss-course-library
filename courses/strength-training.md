# 力量训练计划

> 减脂增肌的科学训练方案，从零基础到进阶

## 核心原则

> 力量训练是减脂的核心——肌肉量增加会提高基础代谢率，即使在休息时也能消耗更多热量。

---

## 1. 减脂增肌黄金法则

**来源**: 搜狐

### 六大法则

| 法则 | 内容 |
|------|------|
| 1. 力量+有氧结合 | 不要只做有氧，力量训练是减脂核心 |
| 2. 吃够蛋白质 | 1.2-1.6g/kg体重 |
| 3. 合理训练频率 | 每周3-4次，留足恢复时间 |
| 4. 不盲目追大重量 | 动作标准比重量重要 |
| 5. 饮食训练同步 | 训练日多吃，休息日适当减少 |
| 6. 长期可持续 | 不追求速成，建立长期习惯 |

### 常见误区

- 只做有氧不做力量 → 肌肉流失，代谢下降
- 热量缺口过大 → 肌肉流失，代谢降低
- 不吃蛋白质 → 无法修复和增长肌肉
- 不休息 → 过度训练，效果反而下降

## 2. 新手入门完整指南 (2026版)

**来源**: R-Star Fitness

### 一周训练计划示例

| 日 | 训练内容 | 时长 |
|----|---------|------|
| 周一 | 全身力量训练A | 45-60分钟 |
| 周二 | 有氧运动 | 30-45分钟 |
| 周三 | 休息/拉伸 | - |
| 周四 | 全身力量训练B | 45-60分钟 |
| 周五 | 有氧运动 | 30-45分钟 |
| 周六 | 全身力量训练C或HIIT | 30-45分钟 |
| 周日 | 休息/轻度活动 | - |

### 单次训练结构

```
热身 (5-10分钟)
  ↓
正式训练 (30-45分钟)
  ↓
拉伸放松 (5-10分钟)
```

### 新手动作推荐

**上肢**:
- 俯卧撑（可跪姿）
- 哑铃推举
- 哑铃划船

**下肢**:
- 深蹲（自重→哑铃→杠铃）
- 箭步蹲
- 臀桥

**核心**:
- 平板支撑
- 死虫式
- 俄罗斯转体

## 3. 肌肉力量训练全攻略

**来源**: 搜狐

### 进阶路径

```
新手期 (0-6个月)
  → 全身训练，每周3次
  → 学习动作模式，建立基础力量

初级期 (6-12个月)
  → 上下分化，每周4次
  → 开始渐进超负荷

中级期 (1-2年)
  → 推拉腿分化，每周5-6次
  → 精细化训练各肌群

高级期 (2年+)
  → 个性化分化方案
  → 关注弱点补强和周期化训练
```

### 复合动作优先

| 动作 | 目标肌群 | 重要性 |
|------|---------|--------|
| 深蹲 | 股四头肌、臀大肌、核心 | ★★★★★ |
| 硬拉 | 后链（臀、腿后、背） | ★★★★★ |
| 卧推 | 胸大肌、三头肌、前束 | ★★★★★ |
| 划船 | 背阔肌、二头肌 | ★★★★☆ |
| 推举 | 三角肌、三头肌 | ★★★★☆ |

### 渐进超负荷原则

- **加重量**: 每周或每两周增加2.5-5%
- **加次数**: 同重量增加重复次数
- **加组数**: 增加训练量
- **减休息**: 缩短组间休息时间

## 4. 三天肌肥大训练计划 (初学者)

**来源**: WorkoutGen

### 训练分化

| 日 | 训练重点 |
|----|---------|
| Day 1 | 胸 + 三头 + 肩前束 |
| Day 2 | 背 + 二头 + 肩后束 |
| Day 3 | 腿 + 肩 + 核心 |

### 示例训练 (Day 1)

| 动作 | 组数 | 次数 | 休息 |
|------|------|------|------|
| 杠铃卧推 | 4 | 8-12 | 90秒 |
| 哑铃飞鸟 | 3 | 10-15 | 60秒 |
| 上斜哑铃推举 | 3 | 10-12 | 90秒 |
| 绳索下压 | 3 | 12-15 | 60秒 |
| 哑铃侧平举 | 3 | 12-15 | 60秒 |

### 恢复计划

- 每周训练3天，休息4天
- 保证每晚7-9小时睡眠
- 训练日蛋白质增加
- 注意补充水分

## 5. 零基础科学增肌减脂指南

**来源**: 知乎

### 底层逻辑

> 新手红利期：增肌和减脂可以同时进行

- 新手在热量缺口不太大的情况下（300-500大卡），可以同时增肌和减脂
- 随着训练经验增加，同时增肌减脂越来越难
- 新手期效果最明显，应充分利用

### 关键要素

| 要素 | 建议 |
|------|------|
| 热量缺口 | 300-500大卡（不宜过大） |
| 蛋白质 | 1.6-2.2g/kg体重 |
| 训练频率 | 每周3-4次力量训练 |
| 睡眠 | 7-9小时 |
| 渐进超负荷 | 持续进步的核心 |
| 坚持 | 至少3个月才能看到明显变化 |
